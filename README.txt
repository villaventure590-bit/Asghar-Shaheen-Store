ASGHAR MEDICAL STORE - STARTER WEBSITE

FILES
- index.html: website page structure
- style.css: colours, layout and mobile responsive design
- script.js: product search, category filters, enquiry list and WhatsApp enquiry

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser (or use Live Server).

IMPORTANT FIRST EDIT
1. Open script.js.
2. Find: const STORE_WHATSAPP = "923000000000";
3. Replace 923000000000 with the store's real WhatsApp number, using country code and digits only.
   Example format: 923001234567
4. Save the file.

BEFORE PUBLIC LAUNCH
- Replace the sample catalogue with products actually stocked by the store.
- Add the real phone number, address, opening hours and delivery/collection policy.
- Add genuine product photos and accurate prices only after checking them.
- This is a front-end starter, not a live inventory, payment or prescription system.
- Do not allow automatic purchase of prescription-only medicines. Have a qualified pharmacist verify prescriptions and provide medicine guidance.
- Protect customer data. A public website needs a secure backend, database, authentication, backups and tested access rules before collecting personal information or orders.
- Confirm applicable Pakistan/Balochistan pharmacy, medicine-sale, privacy and consumer requirements with the relevant authorities before launching online medicine sales.

This starter intentionally uses general health and personal-care catalogue examples, not medical advice.
